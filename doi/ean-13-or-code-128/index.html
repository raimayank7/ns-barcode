EAN-13 जां Code 128: केह्ड़ा बारकोड लैओ

बारकोड दियां किस्मां जेह्ड़ियां तुसें गी मिलङन, कदूं अपने कोड काफी न ते कदूं GS1 India थमां नंबर चाहिदा, चेक डिजिट दी हल कीती दी मसाल कन्नै।

बारकोड दियां किस्मां जेह्ड़ियां तुसें गी मिलङन

किस्मइस च केह् औंदा ऐकुस आस्तै
Code 128कोई बी अक्खर ते नंबरअपनी दुकान जां गोदाम दे अंदर अपने आइटम कोड (जियां NS000123 जां RICE-5KG)
EAN-1313 अंक, आखरी अंक चेक डिजिटदुकानें ते सुपरमार्केटें च बिकने आह्ले प्रोडक्ट; भारत च मते पैकें पर छपे दा नंबर
EAN-88 अंकबड़े निक्के पैक
UPC-A12 अंकUSA ते कनाडा आस्तै बने दे प्रोडक्ट
QR कोडटेक्स्ट जां वेब पतालिंक, लम्मे कोड, जां जदूं फोन दा कैमरा पढ़ग

अपने कोड जां GS1 नंबर?

बारकोड च सिर्फ इक नंबर होंदा ऐ; उसदा मतलब तुंʼदी आइटम लिस्ट थमां औंदा ऐ। अपने बिज़नेस दे अंदर स्कैन करने आस्तै हर आइटम दा बक्खरा कोई बी कोड चलग: कोड देओ दबाओ ते टूल बिना कोड आह्ले आइटमें गी NS000001, NS000002 जनेह् नंबर देई दिंदा ऐ, जेह्ड़े हर आइटम पर सेव होंदे न।

जेकर तुंʼदा प्रोडक्ट होर दुकानां, सुपरमार्केट जां ऑनलाइन मार्केटप्लेस बेचङन, तां ओह् आमतौर पर GTIN मंगदे न: GS1 India थमां तुंʼदे अपने कंपनी प्रीफिक्स पर दित्ता गेदा EAN-13 नंबर (भारत च दित्ते गेदे नंबर आमतौर पर 890 कन्नै शुरू होंदे न)। इसदी GS1 फीस लैंदा ऐ। दुकान थमां बाह्र जाने आह्ले प्रोडक्टें आस्तै EAN-13 नंबर आपूं नेईं बनाओ: ओह् नंबर कुसै होर दे प्रोडक्ट दा होई सकदा ऐ।

20 थमां 29 कन्नै शुरू होने आह्ले नंबर GS1 ने सीमत, दुकान दे अंदर दे बरताव आस्तै रक्खे दे न, जिंʼदे नियम हर देश दा GS1 दफ्तर तय करदा ऐ। इʼनें गी जियां खुल्ला समान तोलियै बेचने आह्लियां दुकानां बरतदियां न। होर बिज़नेसें गी बिकने आह्ले प्रोडक्टें पर इʼनें गी नेईं बरतना चाहिदा।

EAN-13 दा चेक डिजिट कियां बनदा ऐ

13मां अंक स्कैनर गी गलत पढ़ाई फड़न दिंदा ऐ। पैह्ले 12 अंक लैओ; सज्जे पासेआ उʼनें गी बारी-बारी 3 ते 1 कन्नै गुणा करो, जोड़ो, ते चेक डिजिट ओह् अंक ऐ जेह्ड़ा टोटल गी अगले 10 दे गुणज तगर लेई जा।

हल कीती दी मसाल

890123456789 आस्तै: सज्जे पासेआ 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130। अगला 10 दा गुणज आपूं 130 ऐ, इस करी चेक डिजिट 0 ऐ ते पूरा नंबर 8901234567890 ऐ।

12 अंक लिखो तां टूल चेक डिजिट आपूं जोड़ी दिंदा ऐ; 13 लिखो तां उसी चेक करदा ऐ। जेह्ड़ा कोड चुनी दी किस्म च फिट नेईं होऐ ओह् Code 128 च छपदा ऐ, ते टूल दस्सी दिंदा ऐ जे इय्यां दे किन्ने न।
