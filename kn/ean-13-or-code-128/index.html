EAN-13 ಅಥವಾ Code 128: ಯಾವ ಬಾರ್‌ಕೋಡ್ ಬಳಸಬೇಕು

ನಿಮಗೆ ಸಿಗುವ ಬಾರ್‌ಕೋಡ್ ವಿಧಗಳು, ಸ್ವಂತ ಕೋಡ್ ಯಾವಾಗ ಸಾಕು ಮತ್ತು GS1 India ನಂಬರ್ ಯಾವಾಗ ಬೇಕು, ಚೆಕ್ ಡಿಜಿಟ್ ಲೆಕ್ಕದ ಉದಾಹರಣೆಯೊಂದಿಗೆ.

ನಿಮಗೆ ಸಿಗುವ ಬಾರ್‌ಕೋಡ್ ವಿಧಗಳು

ವಿಧಇದರಲ್ಲಿ ಏನಿರುತ್ತದೆಯಾವುದಕ್ಕೆ

ಸ್ವಂತ ಕೋಡ್ ಅಥವಾ GS1 ನಂಬರ್?

ಬಾರ್‌ಕೋಡ್‌ನಲ್ಲಿ ಒಂದು ನಂಬರ್ ಮಾತ್ರ ಇರುತ್ತದೆ; ಅದರ ಅರ್ಥ ನಿಮ್ಮ ಐಟಂ ಲಿಸ್ಟ್‌ನಿಂದ ಬರುತ್ತದೆ. ನಿಮ್ಮ ಬಿಸಿನೆಸ್ ಒಳಗೆ ಸ್ಕ್ಯಾನ್ ಮಾಡಲು ಪ್ರತಿ ಐಟಂಗೆ ಬೇರೆ ಯಾವುದೇ ಕೋಡ್ ಸಾಕು: ಕೋಡ್ ಕೊಡಿ ಒತ್ತಿದರೆ ಟೂಲ್ ಕೋಡ್ ಇಲ್ಲದ ಐಟಂಗಳಿಗೆ NS000001, NS000002 ಮುಂತಾದ ನಂಬರ್ ಕೊಡುತ್ತದೆ, ಅವು ಪ್ರತಿ ಐಟಂ ಮೇಲೆ ಸೇವ್ ಆಗುತ್ತವೆ.

ನಿಮ್ಮ ಉತ್ಪನ್ನವನ್ನು ಬೇರೆ ಅಂಗಡಿಗಳು, ಸೂಪರ್‌ಮಾರ್ಕೆಟ್‌ಗಳು ಅಥವಾ ಆನ್‌ಲೈನ್ ಮಾರ್ಕೆಟ್‌ಪ್ಲೇಸ್‌ಗಳು ಮಾರಿದರೆ, ಅವು ಸಾಮಾನ್ಯವಾಗಿ GTIN ಕೇಳುತ್ತವೆ: GS1 India ನಿಮ್ಮ ಸ್ವಂತ ಕಂಪನಿ ಪ್ರಿಫಿಕ್ಸ್ ಮೇಲೆ ಕೊಡುವ EAN-13 ನಂಬರ್ (ಭಾರತದಲ್ಲಿ ಕೊಡುವ ನಂಬರ್‌ಗಳು ಸಾಮಾನ್ಯವಾಗಿ 890 ರಿಂದ ಶುರುವಾಗುತ್ತವೆ). ಇದಕ್ಕೆ GS1 ಶುಲ್ಕ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ. ಅಂಗಡಿಯಿಂದ ಹೊರಗೆ ಹೋಗುವ ಉತ್ಪನ್ನಗಳಿಗೆ EAN-13 ನಂಬರ್ ನೀವೇ ಮಾಡಬೇಡಿ: ಆ ನಂಬರ್ ಬೇರೆಯವರ ಉತ್ಪನ್ನದ್ದಾಗಿರಬಹುದು.

20 ರಿಂದ 29 ರಿಂದ ಶುರುವಾಗುವ ನಂಬರ್‌ಗಳನ್ನು GS1 ಸೀಮಿತ, ಅಂಗಡಿ ಒಳಗಿನ ಬಳಕೆಗೆ ಇಟ್ಟಿದೆ; ಅವುಗಳ ನಿಯಮವನ್ನು ಪ್ರತಿ ದೇಶದ GS1 ಕಚೇರಿ ನಿರ್ಧರಿಸುತ್ತದೆ. ಉದಾ. ಬಿಡಿ ಸಾಮಾನನ್ನು ತೂಕ ಮಾಡಿ ಮಾರುವ ಅಂಗಡಿಗಳು ಇವನ್ನು ಬಳಸುತ್ತವೆ. ಬೇರೆ ಬಿಸಿನೆಸ್‌ಗಳಿಗೆ ಮಾರುವ ಉತ್ಪನ್ನಗಳ ಮೇಲೆ ಇವನ್ನು ಬಳಸಬಾರದು.

EAN-13 ಚೆಕ್ ಡಿಜಿಟ್ ಹೇಗೆ ಬರುತ್ತದೆ

13ನೇ ಅಂಕಿ ಸ್ಕ್ಯಾನರ್ ತಪ್ಪಾಗಿ ಓದಿದ್ದನ್ನು ಹಿಡಿಯಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ. ಮೊದಲ 12 ಅಂಕಿಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳಿ; ಬಲದಿಂದ ಅವನ್ನು ಸರದಿಯಾಗಿ 3 ಮತ್ತು 1 ರಿಂದ ಗುಣಿಸಿ, ಕೂಡಿಸಿ; ಒಟ್ಟನ್ನು ಮುಂದಿನ 10 ರ ಗುಣಕಕ್ಕೆ ಕೊಂಡೊಯ್ಯುವ ಅಂಕಿಯೇ ಚೆಕ್ ಡಿಜಿಟ್.

ಲೆಕ್ಕ ಮಾಡಿದ ಉದಾಹರಣೆ

890123456789 ಗೆ: ಬಲದಿಂದ 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130. ಮುಂದಿನ 10 ರ ಗುಣಕ 130 ಸ್ವತಃ, ಆದ್ದರಿಂದ ಚೆಕ್ ಡಿಜಿಟ್ 0 ಮತ್ತು ಪೂರ್ಣ ನಂಬರ್ 8901234567890.

12 ಅಂಕಿ ಟೈಪ್ ಮಾಡಿದರೆ ಟೂಲ್ ಚೆಕ್ ಡಿಜಿಟ್ ತಾನೇ ಸೇರಿಸುತ್ತದೆ; 13 ಟೈಪ್ ಮಾಡಿದರೆ ಅದನ್ನು ಚೆಕ್ ಮಾಡುತ್ತದೆ. ಆರಿಸಿದ ವಿಧಕ್ಕೆ ಹೊಂದದ ಕೋಡ್ Code 128 ಆಗಿ ಪ್ರಿಂಟ್ ಆಗುತ್ತದೆ, ಅಂಥವು ಎಷ್ಟು ಎಂದು ಟೂಲ್ ಹೇಳುತ್ತದೆ.
