EAN-13 না Code 128: কোন বারকোড নেবেন

যে বারকোডগুলো আপনি দেখবেন, কখন নিজের কোডই যথেষ্ট আর কখন GS1 India থেকে নম্বর লাগে, চেক ডিজিটের কষে দেখানো উদাহরণ সহ।

যে বারকোডগুলো আপনি দেখবেন

ধরনএতে কী থাকেকীসের জন্য
Code 128যেকোনো অক্ষর ও নম্বরনিজের দোকান বা গুদামের ভেতরে নিজের আইটেম কোড (যেমন NS000123 বা RICE-5KG)
EAN-1313টি সংখ্যা, শেষটি চেক ডিজিটদোকান আর সুপারমার্কেটে বিক্রি হওয়া পণ্য; ভারতে বেশিরভাগ প্যাকে ছাপা নম্বর
EAN-88টি সংখ্যাখুব ছোট প্যাক
UPC-A12টি সংখ্যাUSA আর কানাডার জন্য তৈরি পণ্য
QR কোডলেখা বা ওয়েব ঠিকানালিঙ্ক, লম্বা কোড, বা যখন ফোনের ক্যামেরা পড়বে

নিজের কোড না GS1 নম্বর?

বারকোডে শুধু একটা নম্বর থাকে; তার মানে আসে আপনার আইটেম লিস্ট থেকে। নিজের ব্যবসার ভেতরে স্ক্যান করতে প্রতিটি আইটেমের আলাদা যেকোনো কোড চলবে: কোড দিন চাপুন, টুল কোড-ছাড়া আইটেমগুলোকে NS000001, NS000002-এর মতো নম্বর দেবে, যা প্রতিটি আইটেমে সেভ থাকবে।

আপনার পণ্য যদি অন্য দোকান, সুপারমার্কেট বা অনলাইন মার্কেটপ্লেস বিক্রি করে, তারা সাধারণত GTIN চায়: GS1 India থেকে আপনার নিজের কোম্পানি প্রিফিক্সে দেওয়া EAN-13 নম্বর (ভারতে দেওয়া নম্বর সাধারণত 890 দিয়ে শুরু হয়)। এর জন্য GS1 ফি নেয়। দোকানের বাইরে যাওয়া পণ্যের জন্য নিজে EAN-13 নম্বর বানাবেন না: সেই নম্বর হয়তো অন্য কারও পণ্যের।

20 থেকে 29 দিয়ে শুরু হওয়া নম্বর GS1 সীমিত, দোকানের ভেতরের ব্যবহারের জন্য রেখেছে, যার নিয়ম প্রতিটি দেশের GS1 অফিস ঠিক করে। যেমন খোলা জিনিস ওজন করে বিক্রি করা দোকানগুলো এগুলো ব্যবহার করে। অন্য ব্যবসাকে বিক্রি হওয়া পণ্যে এগুলো ব্যবহার করা চলবে না।

EAN-13-এর চেক ডিজিট কীভাবে হয়

13তম সংখ্যা স্ক্যানারকে ভুল পড়া ধরতে দেয়। প্রথম 12টি সংখ্যা নিন; ডান দিক থেকে পালা করে 3 আর 1 দিয়ে গুণ করুন, যোগ করুন, আর চেক ডিজিট সেই সংখ্যা যা যোগফলকে পরের 10-এর গুণিতকে নিয়ে যায়।

কষে দেখানো উদাহরণ

890123456789-এর জন্য: ডান দিক থেকে 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130। পরের 10-এর গুণিতক 130 নিজেই, তাই চেক ডিজিট 0 আর পুরো নম্বর 8901234567890।

12টি সংখ্যা লিখলে টুল নিজেই চেক ডিজিট জুড়ে দেয়; 13টি লিখলে সেটা যাচাই করে। যে কোড বাছা ধরনে আঁটে না সেটা Code 128-এ ছাপা হয়, আর টুল জানিয়ে দেয় এমন কটা।
