EAN-13 নে Code 128: কোনটো বাৰক'ড ব্যৱহাৰ কৰিব

আপুনি লগ পোৱা বাৰক'ডৰ প্ৰকাৰ, কেতিয়া নিজৰ ক'ডেই যথেষ্ট আৰু কেতিয়া GS1 India ৰ নম্বৰ লাগে, চেক ডিজিটৰ হিচাপ কৰা উদাহৰণৰ সৈতে।

আপুনি লগ পোৱা বাৰক'ডৰ প্ৰকাৰ

প্ৰকাৰইয়াত কি থাকেকিহৰ বাবে
Code 128যিকোনো আখৰ আৰু নম্বৰনিজৰ দোকান বা গুদামৰ ভিতৰত নিজৰ আইটেম ক'ড (যেনে NS000123 বা RICE-5KG)
EAN-1313 টা সংখ্যা, শেষটো চেক ডিজিটদোকান আৰু চুপাৰমাৰ্কেটত বিক্ৰী হোৱা সামগ্ৰী; ভাৰতত বেছিভাগ পেকত ছপা নম্বৰ
EAN-88 টা সংখ্যাবহুত সৰু পেক
UPC-A12 টা সংখ্যাUSA আৰু কানাডাৰ বাবে তৈয়াৰী সামগ্ৰী
QR ক'ডলিখনি বা ৱেব ঠিকনালিংক, দীঘল ক'ড, বা যেতিয়া ফোনৰ কেমেৰাই পঢ়িব

নিজৰ ক'ড নে GS1 নম্বৰ?

বাৰক'ডত কেৱল এটা নম্বৰ থাকে; তাৰ অৰ্থ আপোনাৰ আইটেম লিষ্টৰ পৰা আহে। নিজৰ ব্যৱসায়ৰ ভিতৰত স্কেন কৰিবলৈ প্ৰতিটো আইটেমৰ বেলেগ যিকোনো ক'ড চলিব: ক'ড দিয়ক টিপক, টুলে ক'ড নথকা আইটেমক NS000001, NS000002 ৰ দৰে নম্বৰ দিয়ে, যিবোৰ প্ৰতিটো আইটেমত ছেভ হয়।

আপোনাৰ সামগ্ৰী যদি আন দোকান, চুপাৰমাৰ্কেট বা অনলাইন মাৰ্কেটপ্লেচে বিক্ৰী কৰে, তেওঁলোকে সাধাৰণতে GTIN বিচাৰে: GS1 India এ আপোনাৰ নিজৰ কোম্পানী প্ৰিফিক্সত দিয়া EAN-13 নম্বৰ (ভাৰতত দিয়া নম্বৰ সাধাৰণতে 890 ৰে আৰম্ভ হয়)। ইয়াৰ বাবে GS1 এ মাচুল লয়। দোকানৰ বাহিৰলৈ যোৱা সামগ্ৰীৰ বাবে EAN-13 নম্বৰ নিজে নবনাব: সেই নম্বৰ আন কাৰোবাৰ সামগ্ৰীৰ হ'ব পাৰে।

20 ৰ পৰা 29 লৈ আৰম্ভ হোৱা নম্বৰ GS1 এ সীমিত, দোকানৰ ভিতৰৰ ব্যৱহাৰৰ বাবে ৰাখিছে, যাৰ নিয়ম প্ৰতিখন দেশৰ GS1 অফিচে ঠিক কৰে। যেনে খোলা বস্তু জুখি বেচা দোকানে এইবোৰ ব্যৱহাৰ কৰে। আন ব্যৱসায়ক বিক্ৰী কৰা সামগ্ৰীত এইবোৰ ব্যৱহাৰ কৰিব নালাগে।

EAN-13 ৰ চেক ডিজিট কেনেকৈ আহে

13 নম্বৰ সংখ্যাটোৱে স্কেনাৰক ভুল পঢ়া ধৰিবলৈ দিয়ে। প্ৰথম 12 টা সংখ্যা লওক; সোঁফালৰ পৰা পাল পাতি 3 আৰু 1 ৰে পূৰণ কৰক, যোগ কৰক; মুঠক পিছৰ 10 ৰ গুণিতকলৈ লৈ যোৱা সংখ্যাটোৱেই চেক ডিজিট।

হিচাপ কৰি দেখুওৱা উদাহৰণ

890123456789 ৰ বাবে: সোঁফালৰ পৰা 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130। পিছৰ 10 ৰ গুণিতক 130 নিজেই, সেয়েহে চেক ডিজিট 0 আৰু সম্পূৰ্ণ নম্বৰ 8901234567890।

12 টা সংখ্যা টাইপ কৰিলে টুলে চেক ডিজিট নিজে যোগ কৰে; 13 টা টাইপ কৰিলে সেইটো পৰীক্ষা কৰে। বাছি লোৱা প্ৰকাৰত নিমিলা ক'ড Code 128 ত ছপা হয়, আৰু এনে কেইটা আছে টুলে কয়।
