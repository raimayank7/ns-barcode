ବାରକୋଡ୍ › EAN-13 ନା Code 128

EAN-13 ନା Code 128: କେଉଁ ବାରକୋଡ୍ ବ୍ୟବହାର କରିବେ

ଆପଣ ଦେଖିବାକୁ ପାଉଥିବା ବାରକୋଡ୍ ପ୍ରକାର, ନିଜ କୋଡ୍ କେବେ ଯଥେଷ୍ଟ ଏବଂ GS1 India ନମ୍ବର କେବେ ଦରକାର, ଚେକ୍ ଡିଜିଟର ହିସାବ ଉଦାହରଣ ସହିତ।

ଆପଣ ଦେଖିବାକୁ ପାଉଥିବା ବାରକୋଡ୍ ପ୍ରକାର

ପ୍ରକାରଏଥିରେ କ’ଣ ଥାଏକାହା ପାଇଁ
Code 128ଯେକୌଣସି ଅକ୍ଷର ଓ ନମ୍ବରଆପଣଙ୍କ ଦୋକାନ କିମ୍ବା ଗୋଦାମ ଭିତରେ ନିଜ ଆଇଟମ୍ କୋଡ୍ (ଯେପରି NS000123 କିମ୍ବା RICE-5KG)
EAN-1313 ଅଙ୍କ, ଶେଷଟି ଚେକ୍ ଡିଜିଟ୍ଦୋକାନ ଓ ସୁପରମାର୍କେଟରେ ବିକ୍ରି ହେଉଥିବା ଉତ୍ପାଦ; ଭାରତରେ ଅଧିକାଂଶ ପ୍ୟାକରେ ଛପା ନମ୍ବର

UPC-A12 ଅଙ୍କUSA ଓ କାନାଡା ପାଇଁ ତିଆରି ଉତ୍ପାଦ
QR କୋଡ୍ଲେଖା କିମ୍ବା ୱେବ୍ ଠିକଣାଲିଙ୍କ, ଲମ୍ବା କୋଡ୍, କିମ୍ବା ଫୋନ୍ କ୍ୟାମେରା ପଢ଼ିବା ବେଳେ

ନିଜ କୋଡ୍ ନା GS1 ନମ୍ବର?

ବାରକୋଡରେ କେବଳ ଗୋଟିଏ ନମ୍ବର ଥାଏ; ତା’ର ଅର୍ଥ ଆପଣଙ୍କ ଆଇଟମ୍ ଲିଷ୍ଟରୁ ଆସେ। ନିଜ ବ୍ୟବସାୟ ଭିତରେ ସ୍କାନ୍ କରିବାକୁ ପ୍ରତି ଆଇଟମର ଅଲଗା ଯେକୌଣସି କୋଡ୍ ଚଳିବ: କୋଡ୍ ଦିଅନ୍ତୁ ଦବାନ୍ତୁ, ଟୁଲ୍ କୋଡ୍ ନଥିବା ଆଇଟମକୁ NS000001, NS000002 ଭଳି ନମ୍ବର ଦିଏ, ଯାହା ପ୍ରତି ଆଇଟମରେ ସେଭ୍ ହୁଏ।

ଆପଣଙ୍କ ଉତ୍ପାଦ ଯଦି ଅନ୍ୟ ଦୋକାନ, ସୁପରମାର୍କେଟ କିମ୍ବା ଅନଲାଇନ୍ ମାର୍କେଟପ୍ଲେସ୍ ବିକ୍ରି କରିବେ, ସେମାନେ ସାଧାରଣତଃ GTIN ମାଗନ୍ତି: GS1 India ଆପଣଙ୍କ ନିଜ କମ୍ପାନୀ ପ୍ରିଫିକ୍ସରେ ଦେଉଥିବା EAN-13 ନମ୍ବର (ଭାରତରେ ଦିଆଯାଉଥିବା ନମ୍ବର ସାଧାରଣତଃ 890 ରୁ ଆରମ୍ଭ ହୁଏ)। ଏଥିପାଇଁ GS1 ଫି ନିଏ। ଦୋକାନ ବାହାରକୁ ଯାଉଥିବା ଉତ୍ପାଦ ପାଇଁ EAN-13 ନମ୍ବର ନିଜେ ତିଆରି କରନ୍ତୁ ନାହିଁ: ସେହି ନମ୍ବର ଅନ୍ୟ କାହାର ଉତ୍ପାଦର ହୋଇପାରେ।

20 ରୁ 29 ରୁ ଆରମ୍ଭ ହେଉଥିବା ନମ୍ବର GS1 ସୀମିତ, ଦୋକାନ ଭିତର ବ୍ୟବହାର ପାଇଁ ରଖିଛି, ଯାହାର ନିୟମ ପ୍ରତି ଦେଶର GS1 ଅଫିସ୍ ସ୍ଥିର କରେ। ଯେପରି ଖୋଲା ଜିନିଷ ଓଜନ କରି ବିକୁଥିବା ଦୋକାନ ଏଗୁଡ଼ିକ ବ୍ୟବହାର କରନ୍ତି। ଅନ୍ୟ ବ୍ୟବସାୟକୁ ବିକ୍ରି ହେଉଥିବା ଉତ୍ପାଦରେ ଏଗୁଡ଼ିକ ବ୍ୟବହାର କରିବା ଉଚିତ ନୁହେଁ।

EAN-13 ଚେକ୍ ଡିଜିଟ୍ କିପରି ଆସେ

13ତମ ଅଙ୍କ ସ୍କାନରକୁ ଭୁଲ ପଢ଼ା ଧରିବାରେ ସାହାଯ୍ୟ କରେ। ପ୍ରଥମ 12 ଅଙ୍କ ନିଅନ୍ତୁ; ଡାହାଣରୁ ପାଳି କରି 3 ଓ 1 ରେ ଗୁଣନ୍ତୁ, ଯୋଡ଼ନ୍ତୁ; ମୋଟକୁ ପରବର୍ତ୍ତୀ 10 ର ଗୁଣିତକକୁ ନେଉଥିବା ଅଙ୍କ ହିଁ ଚେକ୍ ଡିଜିଟ୍।

ହିସାବ କରାଯାଇଥିବା ଉଦାହରଣ

890123456789 ପାଇଁ: ଡାହାଣରୁ 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130। ପରବର୍ତ୍ତୀ 10 ର ଗୁଣିତକ 130 ନିଜେ, ତେଣୁ ଚେକ୍ ଡିଜିଟ୍ 0 ଏବଂ ପୂରା ନମ୍ବର 8901234567890।

12 ଅଙ୍କ ଟାଇପ୍ କଲେ ଟୁଲ୍ ଚେକ୍ ଡିଜିଟ୍ ନିଜେ ଯୋଡ଼େ; 13 ଟାଇପ୍ କଲେ ତାହା ଯାଞ୍ଚ କରେ। ବଛା ପ୍ରକାରରେ ଖାପ ନଖାଉଥିବା କୋଡ୍ Code 128 ରେ ଛପା ହୁଏ, ଏବଂ ଏପରି କେତୋଟି ତାହା ଟୁଲ୍ କହେ।
