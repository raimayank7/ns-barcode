ബാർകോഡ് ലേബൽ സൈസുകൾEAN-13 അല്ലെങ്കിൽ Code 128Nivesh Sahayak App

ബാർകോഡ് › ബാർകോഡ് ലേബൽ പ്രിന്റ്

ഷീറ്റുമായി ഒക്കുന്ന ബാർകോഡ് ലേബൽ എങ്ങനെ പ്രിന്റ് ചെയ്യാം

ഘട്ടം ഘട്ടമായ പ്രിന്റിങ്, പ്രധാന പ്രിന്റർ സെറ്റിങ്സ്, ഷീറ്റ് പാഴാക്കും മുൻപ് ടെസ്റ്റ്, ആദ്യ തവണ തന്നെ സ്കാൻ ആകുന്ന ബാർകോഡുകൾ.

ഘട്ടം ഘട്ടമായി

  1. ഐറ്റങ്ങൾ ടിക്ക് ചെയ്യുക, വേണമെങ്കിൽ വില മാറ്റുക, ഓരോന്നിനും എത്ര ലേബൽ വേണമെന്ന് ടൈപ്പ് ചെയ്യുക. അല്ലെങ്കിൽ നിങ്ങളുടെ ഐറ്റങ്ങളിൽ ഇല്ലാത്ത കോഡിനായി കൈകൊണ്ട് ലേബൽ അമർത്തുക.
  2. ഷീറ്റ് അല്ലെങ്കിൽ ലേബൽ റോൾ, ബാർകോഡ് തരം, എന്ത് കാണിക്കണം എന്നിവ തിരഞ്ഞെടുക്കുക: ഐറ്റത്തിന്റെ പേര്, ബാർകോഡിന് താഴെ കോഡ്, MRP അല്ലെങ്കിൽ വില മാത്രം, നിങ്ങളുടെ ബിസിനസ് പേര്.
  3. പകുതി ഉപയോഗിച്ച ഷീറ്റിൽ ലേബൽ നം. മുതൽ തുടങ്ങുക-യിൽ ആദ്യത്തെ ഒഴിഞ്ഞ ലേബൽ എഴുതുക; എണ്ണം ആദ്യ വരിയിൽ ഇടത്തുനിന്ന് വലത്തോട്ട്, പിന്നെ അടുത്ത വരിയിൽ.
  4. പ്രിവ്യൂ നോക്കി പ്രിന്റ് അമർത്തുക. A4 ഷീറ്റിന് PDF ഷെയർ ചെയ്യുക വഴി PDF ഉണ്ടാക്കി പിന്നീടും പ്രിന്റ് ചെയ്യാം.

പ്രധാന പ്രിന്റർ സെറ്റിങ്സ്

  • Scale 100% / യഥാർത്ഥ സൈസ്. "Fit to page" എല്ലാം ചെറുതാക്കും, ലേബലുകൾ ഷീറ്റുമായി ഒക്കില്ല.
  • Margins: none (അല്ലെങ്കിൽ minimum), headers, footers ഓഫ്, അപ്പോൾ ബ്രൗസർ ലേബലിൽ തീയതിയും വിലാസവും അച്ചടിക്കില്ല.
  • ഷീറ്റിന് പേപ്പർ സൈസ് A4, ലേബൽ പ്രിന്ററിന് കൃത്യം അതേ ലേബൽ സൈസ്.
  • ലേസർ പ്രിന്റർ: ലേസറിനായി ഉണ്ടാക്കിയ ഷീറ്റുകൾ മാത്രം ഉപയോഗിക്കുക; ഇങ്ക്ജെറ്റ് ഷീറ്റുകൾ ചുരുളുകയോ മഷി പടരുകയോ ചെയ്യാം.

ഷീറ്റ് പാഴാക്കും മുൻപ് ടെസ്റ്റ് ചെയ്യുക

ആദ്യ പേജ് സാധാരണ പേപ്പറിൽ പ്രിന്റ് ചെയ്ത്, ലേബൽ ഷീറ്റിനൊപ്പം വെളിച്ചത്തിനു മുന്നിൽ പിടിച്ച്, ഓരോ ബാർകോഡും ലേബലിനകത്താണോ എന്ന് നോക്കുക. എല്ലാം ഒരേ വശത്തേക്ക് നീങ്ങിയെങ്കിൽ എന്റെ സ്വന്തം സൈസ്-ൽ മുകളിലെ അല്ലെങ്കിൽ ഇടത് മാർജിൻ മാറ്റുക. പേജിലൂടെ മുന്നോട്ടു പോകുമ്പോൾ നീക്കം കൂടിവരുന്നുവെങ്കിൽ, ലേബൽ വീതിയോ ഗ്യാപ്പോ അൽപം തെറ്റാണ്.

ബാർകോഡുകൾ നന്നായി സ്കാൻ ആകാൻ

  • വെള്ള അല്ലെങ്കിൽ ഇളം ലേബലിൽ കറുത്ത വരകൾ. ചുവന്ന വരകൾ വേണ്ട: പല സ്കാനറുകളും ചുവന്ന വെളിച്ചം ഉപയോഗിക്കുന്നതിനാൽ അവ കാണില്ല.
  • വരകളുടെ ഇരുവശത്തും ഒഴിഞ്ഞ വെള്ള സ്ഥലം വിടുക; ടൂൾ ചെറിയ മാർജിൻ സൂക്ഷിക്കും.
  • ബാർകോഡിന് വേണ്ടതിലും ഇടുങ്ങിയ ലേബൽ ആക്കരുത്. നീണ്ട Code 128 കോഡുകൾക്ക് വീതിയുള്ള ലേബൽ വേണം; സ്കാൻ ആകുന്നില്ലെങ്കിൽ കോഡ് ചുരുക്കുക.
  • തെർമൽ ലേബലുകൾ ചൂടിലും വെയിലിലും മങ്ങും. മാസങ്ങളോളം സൂക്ഷിക്കുന്ന സാധനങ്ങൾക്ക് നല്ല ലേബൽ ഉപയോഗിക്കുക അല്ലെങ്കിൽ വെയിലിൽ നിന്ന് മാറ്റിവയ്ക്കുക.
