EAN-13 അല്ലെങ്കിൽ Code 128: ഏത് ബാർകോഡ് ഉപയോഗിക്കണം

നിങ്ങൾ കാണുന്ന ബാർകോഡ് തരങ്ങൾ, സ്വന്തം കോഡ് എപ്പോൾ മതി, GS1 India നമ്പർ എപ്പോൾ വേണം, ചെക്ക് ഡിജിറ്റ് കണക്കാക്കിയ ഉദാഹരണത്തോടെ.

നിങ്ങൾ കാണുന്ന ബാർകോഡ് തരങ്ങൾ

തരംഇതിൽ എന്തുണ്ടാകുംഎന്തിന്
Code 128ഏത് അക്ഷരവും നമ്പറുംനിങ്ങളുടെ കടയിലോ ഗോഡൗണിലോ സ്വന്തം ഐറ്റം കോഡുകൾ (ഉദാ. NS000123 അല്ലെങ്കിൽ RICE-5KG)
EAN-1313 അക്കം, അവസാനത്തേത് ചെക്ക് ഡിജിറ്റ്കടകളിലും സൂപ്പർമാർക്കറ്റുകളിലും വിൽക്കുന്ന ഉൽപന്നങ്ങൾ; ഇന്ത്യയിൽ മിക്ക പാക്കിലും അച്ചടിച്ച നമ്പർ
EAN-88 അക്കംവളരെ ചെറിയ പാക്കുകൾ
UPC-A12 അക്കംUSA, കാനഡ എന്നിവയ്ക്കായി ഉണ്ടാക്കിയ ഉൽപന്നങ്ങൾ
QR കോഡ്ടെക്സ്റ്റ് അല്ലെങ്കിൽ വെബ് വിലാസംലിങ്കുകൾ, നീണ്ട കോഡുകൾ, അല്ലെങ്കിൽ ഫോൺ ക്യാമറ വായിക്കുമ്പോൾ

സ്വന്തം കോഡോ GS1 നമ്പറോ?

ബാർകോഡിൽ ഒരു നമ്പർ മാത്രമേ ഉള്ളൂ; അതിന്റെ അർഥം നിങ്ങളുടെ ഐറ്റം ലിസ്റ്റിൽ നിന്ന് വരുന്നു. നിങ്ങളുടെ ബിസിനസിനകത്ത് സ്കാൻ ചെയ്യാൻ ഓരോ ഐറ്റത്തിനും വേറിട്ട ഏത് കോഡും മതി: കോഡ് നൽകുക അമർത്തിയാൽ കോഡ് ഇല്ലാത്ത ഐറ്റങ്ങൾക്ക് ടൂൾ NS000001, NS000002 പോലുള്ള നമ്പറുകൾ നൽകും, അവ ഓരോ ഐറ്റത്തിലും സേവ് ആകും.

നിങ്ങളുടെ ഉൽപന്നം മറ്റ് കടകളോ സൂപ്പർമാർക്കറ്റുകളോ ഓൺലൈൻ മാർക്കറ്റ്പ്ലേസുകളോ വിൽക്കുമെങ്കിൽ, അവർ സാധാരണ GTIN ചോദിക്കും: GS1 India നിങ്ങളുടെ സ്വന്തം കമ്പനി പ്രിഫിക്സിൽ നൽകുന്ന EAN-13 നമ്പർ (ഇന്ത്യയിൽ നൽകുന്ന നമ്പറുകൾ സാധാരണ 890-ൽ തുടങ്ങും). ഇതിന് GS1 ഫീസ് ഈടാക്കും. കടയ്ക്ക് പുറത്തുപോകുന്ന ഉൽപന്നങ്ങൾക്ക് EAN-13 നമ്പർ സ്വയം ഉണ്ടാക്കരുത്: ആ നമ്പർ മറ്റാരുടെയെങ്കിലും ഉൽപന്നത്തിന്റേതാകാം.

20 മുതൽ 29 വരെ തുടങ്ങുന്ന നമ്പറുകൾ GS1 പരിമിതമായ, കടയ്ക്കകത്തെ ഉപയോഗത്തിനായി മാറ്റിവച്ചിരിക്കുന്നു; അവയുടെ നിയമങ്ങൾ ഓരോ രാജ്യത്തെയും GS1 ഓഫീസ് തീരുമാനിക്കുന്നു. ഉദാ. ലൂസ് സാധനങ്ങൾ തൂക്കി വിൽക്കുന്ന കടകൾ ഇവ ഉപയോഗിക്കുന്നു. മറ്റ് ബിസിനസുകൾക്ക് വിൽക്കുന്ന ഉൽപന്നങ്ങളിൽ ഇവ ഉപയോഗിക്കരുത്.

EAN-13 ചെക്ക് ഡിജിറ്റ് എങ്ങനെ വരുന്നു

13-ാം അക്കം സ്കാനർ തെറ്റായി വായിച്ചത് പിടിക്കാൻ സഹായിക്കുന്നു. ആദ്യത്തെ 12 അക്കങ്ങൾ എടുക്കുക; വലത്തുനിന്ന് മാറിമാറി 3, 1 കൊണ്ട് ഗുണിച്ച് കൂട്ടുക; ആകെത്തുകയെ അടുത്ത 10-ന്റെ ഗുണിതത്തിലേക്ക് എത്തിക്കുന്ന അക്കമാണ് ചെക്ക് ഡിജിറ്റ്.

കണക്കാക്കിയ ഉദാഹരണം

890123456789-ന്: വലത്തുനിന്ന് 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130. അടുത്ത 10-ന്റെ ഗുണിതം 130 തന്നെ, അതിനാൽ ചെക്ക് ഡിജിറ്റ് 0, പൂർണ നമ്പർ 8901234567890.

12 അക്കം ടൈപ്പ് ചെയ്താൽ ടൂൾ ചെക്ക് ഡിജിറ്റ് സ്വയം ചേർക്കും; 13 ടൈപ്പ് ചെയ്താൽ അത് പരിശോധിക്കും. തിരഞ്ഞെടുത്ത തരത്തിൽ ചേരാത്ത കോഡ് Code 128 ആയി അച്ചടിക്കും, അങ്ങനെ എത്രയെണ്ണം എന്ന് ടൂൾ പറയും.
