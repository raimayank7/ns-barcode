EAN-13 કે Code 128: કયો બારકોડ વાપરવો

તમને મળતા બારકોડના પ્રકાર, પોતાના કોડ ક્યારે પૂરતા અને GS1 India પાસેથી નંબર ક્યારે જોઈએ, ચેક ડિજિટના ગણેલા ઉદાહરણ સાથે.

તમને મળતા બારકોડના પ્રકાર

પ્રકારતેમાં શું આવેશેના માટે
Code 128કોઈ પણ અક્ષર અને નંબરતમારી દુકાન કે ગોડાઉનમાં તમારા પોતાના આઇટમ કોડ (જેમ કે NS000123 કે RICE-5KG)
EAN-1313 અંક, છેલ્લો અંક ચેક ડિજિટદુકાનો અને સુપરમાર્કેટમાં વેચાતી પ્રોડક્ટ; ભારતમાં મોટા ભાગના પેક પર છાપેલો નંબર
EAN-88 અંકખૂબ નાના પેક
UPC-A12 અંકUSA અને કેનેડા માટે બનેલી પ્રોડક્ટ
QR કોડલખાણ કે વેબ સરનામુંલિંક, લાંબા કોડ, કે જ્યારે ફોન કેમેરા વાંચશે

પોતાના કોડ કે GS1 નંબર?

બારકોડમાં ફક્ત એક નંબર હોય છે; તેનો અર્થ તમારી આઇટમ લિસ્ટમાંથી આવે છે. તમારા બિઝનેસની અંદર સ્કેન કરવા દરેક આઇટમનો જુદો કોઈ પણ કોડ ચાલે: કોડ આપો દબાવો અને ટૂલ કોડ વગરની આઇટમને NS000001, NS000002 જેવા નંબર આપે છે, જે દરેક આઇટમ પર સેવ થાય છે.

જો તમારી પ્રોડક્ટ બીજી દુકાનો, સુપરમાર્કેટ કે ઓનલાઇન માર્કેટપ્લેસ વેચશે, તો તેઓ સામાન્ય રીતે GTIN માંગે છે: GS1 India તરફથી તમારા પોતાના કંપની પ્રીફિક્સ પર આપેલો EAN-13 નંબર (ભારતમાં આપેલા નંબર સામાન્ય રીતે 890 થી શરૂ થાય છે). આ માટે GS1 ફી લે છે. દુકાનની બહાર જતી પ્રોડક્ટ માટે EAN-13 નંબર જાતે ન બનાવો: એ નંબર કોઈ બીજાની પ્રોડક્ટનો હોઈ શકે.

20 થી 29 થી શરૂ થતા નંબર GS1 એ મર્યાદિત, દુકાનની અંદરના ઉપયોગ માટે રાખ્યા છે, જેના નિયમો દરેક દેશની GS1 ઓફિસ નક્કી કરે છે. જેમ કે છૂટો માલ તોલીને વેચતી દુકાનો તે વાપરે છે. બીજા બિઝનેસને વેચાતી પ્રોડક્ટ પર તે ન વાપરવા.

EAN-13 નો ચેક ડિજિટ કેવી રીતે આવે

13મો અંક સ્કેનરને ખોટું વાંચન પકડવા દે છે. પહેલા 12 અંક લો; જમણેથી તેમને વારાફરતી 3 અને 1 વડે ગુણો, સરવાળો કરો, અને ચેક ડિજિટ એ અંક છે જે સરવાળાને આગળના 10 ના ગુણાંક સુધી લઈ જાય.

ગણેલું ઉદાહરણ

890123456789 માટે: જમણેથી 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130. આગળનો 10 નો ગુણાંક પોતે 130 છે, એટલે ચેક ડિજિટ 0 અને પૂરો નંબર 8901234567890.

12 અંક લખો તો ટૂલ ચેક ડિજિટ જાતે ઉમેરે છે; 13 લખો તો તેને તપાસે છે. પસંદ કરેલા પ્રકારમાં ન બેસતો કોડ Code 128 માં છપાય છે, અને આવા કેટલા છે તે ટૂલ કહે છે.
