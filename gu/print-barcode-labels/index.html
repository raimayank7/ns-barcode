બારકોડ › બારકોડ લેબલ પ્રિન્ટ

શીટ સાથે મેળ ખાતા બારકોડ લેબલ કેવી રીતે પ્રિન્ટ કરવા

પગલે પગલે પ્રિન્ટિંગ, જરૂરી પ્રિન્ટર સેટિંગ, શીટ બગાડતા પહેલાં ટેસ્ટ, અને પહેલી વારમાં જ સ્કેન થતા બારકોડ.

પગલે પગલે

  1. આઇટમ પર ટિક કરો, જરૂર હોય તો ભાવ બદલો, અને દરેકના કેટલા લેબલ જોઈએ તે લખો. અથવા તમારી આઇટમમાં ન હોય તેવા કોડ માટે હાથથી લેબલ દબાવો.
  2. શીટ કે લેબલ રોલ, બારકોડનો પ્રકાર, અને શું બતાવવું તે પસંદ કરો: આઇટમનું નામ, બારકોડ નીચે કોડ, MRP કે ફક્ત ભાવ, અને તમારા બિઝનેસનું નામ.
  3. અડધી વપરાયેલી શીટ પર લેબલ નં. થી શરૂ કરો માં પહેલું ખાલી લેબલ લખો; ગણતરી પહેલી લાઇનમાં ડાબેથી જમણે, પછી આગળની લાઇનમાં ચાલે છે.
  4. પ્રિવ્યૂ જુઓ, પછી પ્રિન્ટ દબાવો. A4 શીટ માટે PDF શેર કરો થી PDF બનાવીને પછીથી પણ પ્રિન્ટ કરી શકો.

પ્રિન્ટરની જરૂરી સેટિંગ

  • Scale 100% / અસલ સાઇઝ. "Fit to page" બધું નાનું કરી દે છે અને લેબલ શીટ સાથે મેળ ખાતા નથી.
  • Margins: none (કે minimum) અને headers અને footers બંધ, જેથી બ્રાઉઝર લેબલ પર તારીખ અને સરનામું ન છાપે.
  • શીટ માટે પેપર સાઇઝ A4, કે લેબલ પ્રિન્ટર માટે બરાબર એ જ લેબલ સાઇઝ.
  • લેઝર પ્રિન્ટર: લેઝર માટે બનેલી શીટ જ લો; ઇંકજેટ શીટ વળી શકે કે શાહી ફેલાઈ શકે.

શીટ બગાડતા પહેલાં ટેસ્ટ કરો

પહેલું પેજ સાદા કાગળ પર પ્રિન્ટ કરો, તેને લેબલ શીટ સાથે પ્રકાશ સામે રાખો, અને જુઓ કે દરેક બારકોડ લેબલની અંદર છે. બધું એક જ બાજુ ખસ્યું હોય તો મારી પોતાની સાઇઝ માં ઉપરનું કે ડાબું માર્જિન બદલો. પેજ પર આગળ જતાં ખસવું વધતું જાય તો લેબલની પહોળાઈ કે ગેપ થોડો ખોટો છે.

બારકોડ બરાબર સ્કેન થાય તે માટે

  • સફેદ કે આછા લેબલ પર કાળી લીટીઓ. લાલ લીટીઓ ન રાખો: ઘણા સ્કેનર લાલ પ્રકાશ વાપરે છે અને તેમને તે દેખાતી નથી.
  • લીટીઓની બંને બાજુ ખાલી સફેદ જગ્યા રાખો; ટૂલ થોડું માર્જિન રાખે છે.
  • બારકોડને જોઈએ તેના કરતાં લેબલ સાંકડું ન કરો. લાંબા Code 128 કોડને પહોળા લેબલ જોઈએ; સ્કેન ન થાય તો કોડ ટૂંકા કરો.
  • થર્મલ લેબલ ગરમી અને તડકામાં ઝાંખા પડે છે. મહિનાઓ સુધી રાખવાના માલ માટે સારા લેબલ લો કે તડકાથી દૂર રાખો.
તમારા લેબલની પહેલી શીટ પ્રિન્ટ કરો.ટૂલ ખોલો
