EAN-13 or Code 128: which barcode to use

The barcode types you will meet, when your own codes are enough and when you need a number from GS1 India, with the check digit worked out.

The barcode types you will meet

TypeHoldsUse it for
Code 128Any letters and numbersYour own item codes inside your shop or godown (for example NS000123 or RICE-5KG)
EAN-1313 digits, the last one a check digitProducts sold through shops and supermarkets; the number printed on most packs in India
EAN-88 digitsVery small packs
UPC-A12 digitsProducts made for the USA and Canada
QR codeText or a web addressLinks, long codes, or when a phone camera will read it

Your own codes or GS1 numbers?

A barcode only holds a number; the meaning comes from your item list. For scanning inside your own business, any code that is unique for each item works: press Give codes and the tool gives items without a code numbers like NS000001, NS000002, saved on each item.

If your product will be sold by other shops, supermarkets or online marketplaces, they will usually ask for a GTIN: an EAN-13 number issued under your own company prefix from GS1 India (numbers issued in India usually start with 890). GS1 charges a fee for this. Do not make up EAN-13 numbers for products that leave your shop: the number may already belong to someone else's product.

Numbers starting with 20 to 29 are kept by GS1 for restricted, in-store use, with rules set by each country's GS1 office. They are used, for example, by shops that weigh loose goods. They must not be used on products sold to other businesses.

How the EAN-13 check digit works

The 13th digit lets the scanner catch a misread. Take the first 12 digits; from the right, multiply them alternately by 3 and 1, add up, and the check digit is what brings the total to the next multiple of 10.

Worked example

For 890123456789: from the right, 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130. The next multiple of 10 is 130 itself, so the check digit is 0 and the full number is 8901234567890.

Type 12 digits and the tool adds the check digit for you; type 13 and it checks it. A code that does not fit the chosen type prints as Code 128 instead, and the tool tells you how many.
