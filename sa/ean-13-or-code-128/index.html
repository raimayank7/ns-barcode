EAN-13 उत Code 128: कः बारकोडः उपयोक्तव्यः

भवता दृश्यमानाः बारकोड-प्रकाराः, कदा स्वकीयानि कोडानि पर्याप्तानि कदा GS1 India नंबर आवश्यकम्, चेक डिजिटस्य गणितेन उदाहरणेन सह।

भवता दृश्यमानाः बारकोड-प्रकाराः

प्रकारःअस्मिन् किं भवतिकिमर्थम्
Code 128कानिचित् अपि अक्षराणि नंबराणि चस्वस्य आपणे गोदामे वा स्वकीयानि आइटम-कोडानि (यथा NS000123 अथवा RICE-5KG)
EAN-1313 अङ्काः, अन्तिमः चेक डिजिटआपणेषु सुपरमार्केटेषु च विक्रीयमाणाः उत्पादाः; भारते अधिकेषु पैकेषु मुद्रितं नंबर
EAN-88 अङ्काःअतिलघवः पैकाः
UPC-A12 अङ्काःUSA कनाडा च कृते निर्मिताः उत्पादाः
QR कोडपाठः वेब-पता वालिंक, दीर्घकोडानि, यदा वा फोन-कैमरा पठिष्यति

स्वकीयानि कोडानि उत GS1 नंबराणि?

बारकोडे केवलम् एकं नंबर भवति; तस्य अर्थः भवतः आइटम-लिस्टतः आगच्छति। स्वव्यवसायस्य अन्तः स्कैनार्थं प्रत्येकस्य आइटमस्य भिन्नं किमपि कोड पर्याप्तम्: कोड ददातु नुदतु, टूलः कोडरहितेभ्यः आइटमेभ्यः NS000001, NS000002 इव नंबराणि ददाति, यानि प्रत्येकस्मिन् आइटमे सेव भवन्ति।

यदि भवतः उत्पादम् अन्ये आपणाः सुपरमार्केटाः ऑनलाइन-मार्केटप्लेसाः वा विक्रेष्यन्ति, ते प्रायः GTIN याचन्ते: GS1 India द्वारा भवतः स्वकीय-कंपनी-प्रीफिक्से दत्तं EAN-13 नंबर (भारते दत्तानि नंबराणि प्रायः 890 तः आरभन्ते)। अस्य कृते GS1 शुल्कं गृह्णाति। आपणात् बहिः गच्छतां उत्पादानां कृते EAN-13 नंबराणि स्वयं मा रचयतु: तत् नंबर अन्यस्य उत्पादस्य भवितुम् अर्हति।

20 तः 29 पर्यन्तम् आरभमाणानि नंबराणि GS1 सीमितस्य आपणान्तर्गतस्य उपयोगस्य कृते रक्षति, येषां नियमान् प्रत्येकस्य देशस्य GS1 कार्यालयं निर्धारयति। यथा मुक्तवस्तूनि तोलयित्वा विक्रीणन्तः आपणाः एतानि उपयुञ्जते। अन्यव्यवसायेभ्यः विक्रीयमाणेषु उत्पादेषु एतानि न उपयोक्तव्यानि।

EAN-13 चेक डिजिट कथं भवति

त्रयोदशः अङ्कः स्कैनराय दोषपूर्णं पठनं ग्रहीतुं साहाय्यं करोति। प्रथमान् 12 अङ्कान् गृह्णातु; दक्षिणतः क्रमशः 3 1 च इत्याभ्यां गुणयतु, योजयतु; योगं अग्रिमं 10 इत्यस्य गुणितं प्रति नयन् अङ्कः एव चेक डिजिट।

गणितम् उदाहरणम्

890123456789 कृते: दक्षिणतः 9×3 + 8×1 + 7×3 + 6×1 + 5×3 + 4×1 + 3×3 + 2×1 + 1×3 + 0×1 + 9×3 + 8×1 = 27+8+21+6+15+4+9+2+3+0+27+8 = 130। अग्रिमं 10 इत्यस्य गुणितं स्वयं 130, अतः चेक डिजिट 0, पूर्णं नंबर 8901234567890।

12 अङ्कान् टाइप करोति चेत् टूलः चेक डिजिट स्वयं योजयति; 13 टाइप करोति चेत् तत् परीक्षते। चितप्रकारे अयुक्तं कोड Code 128 रूपेण मुद्र्यते, कति एतादृशानि इति टूलः वदति।
