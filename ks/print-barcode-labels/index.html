بارکوڈ › بارکوڈ لیبل پرنٹ

شیٖٹِ سٟتۍ میلن وٲلۍ بارکوڈ لیبل کِتھہٕ پٲٹھۍ کرَو پرنٹ

قدم قدم پرنٹنگ، ضروری پرنٹر سیٹنگ، شیٖٹ خراب کرنہٕ برونٛہہ ٹیسٹ، تہٕ گۄڈنِچ لٹہِ سکین گژھن وٲلۍ بارکوڈ۔

قدم قدم

  1. آئٹمن پیٚٹھ کٔرِو ٹِک، ضرورت آسہِ تیٚلہِ بدلٲوِو ریٹ، تہٕ لیٚکھِو پرٛتھ اَکِس کوتاہ لیبل گژھن۔ یا یُس کوڈ تُہٕنٛدِس آئٹمن منٛز چھُنہٕ تَمہِ خٲطرٕ دبٲوِو اَتھہٕ سٟتۍ لیبل۔
  2. ژارِو شیٖٹ یا لیبل رول، بارکوڈٕچ قٕسم، تہٕ کیاہ ہاوُن: آئٹمُک ناو، بارکوڈ تَل کوڈ، MRP یا صرف ریٹ، تہٕ تُہٕنٛدِس بزنسُک ناو۔
  3. اَڑِ ورتاونہٕ آمژِ شیٖٹِ پیٚٹھ لیٚکھِو لیبل نمبر پیٚٹھہٕ شروٗع کٔرِو منٛز گۄڈنیُک خٲلی لیبل؛ گَنٛزرٕ چھےٚ گۄڈنِچ قطارِ منٛز کھوٚوُرہِ پیٚٹھہٕ دٔچھنس، پتہٕ بییِس قطارِ منٛز پَکان۔
  4. وُچھِو پریویو، پتہٕ دبٲوِو پرنٹ۔ A4 شیٖٹن خٲطرٕ ہیٚکِو PDF شیئر کٔرِو سٟتۍ PDF بنٲوِتھ پتہٕ تہِ پرنٹ کٔرِتھ۔

پرنٹرٕچ ضروری سیٹنگ

  • Scale 100% / اصل سائز۔ "Fit to page" چھُ سورُے لۄکُٹ کران تہٕ لیبل چھِنہٕ شیٖٹِ سٟتۍ میلان۔
  • Margins: none (یا minimum) تہٕ headers تہٕ footers بند، تاکہ براوزر نہٕ لیبلن پیٚٹھ تٲریخ تہٕ پتہٕ چھاپہِ۔
  • شیٖٹن خٲطرٕ پیپر سائز A4، یا لیبل پرنٹرس خٲطرٕ ٹھیک سُے لیبل سائز۔
  • لیزر پرنٹر: ہیٚیِو لیزرس خٲطرٕ بنیمژ شیٖٹٕے؛ انک جیٹ شیٖٹ ہیٚکہِ ؤلِتھ یا سیاہی ہیٚکہِ پھٲلِتھ۔

شیٖٹ خراب کرنہٕ برونٛہہ کٔرِو ٹیسٹ

گۄڈنیُک پیج کٔرِو سادٕ کاغزس پیٚٹھ پرنٹ، تھٲوِو تہٕ لیبل شیٖٹِ سٟتۍ گاشس برونٛہہ کنہِ، تہٕ وُچھِو زِ پرٛتھ بارکوڈ چھا لیبلس اندر۔ اگر سورُے اکے طرفہٕ ہیوٚر چھُ، تیٚلہِ بدلٲوِو میون پَنُن سائز منٛز ہیٚرِم یا کھوٚور مارجن۔ اگر پیجس پیٚٹھ برونٛہہ گژھان گژھان ہیوٚر یُن ہُرِ، تیٚلہِ چھےٚ لیبلچ کھُلٲے یا گیپ کینٛہہ غلط۔

بارکوڈ گژھن ٹھیک سکین

  • سفید یا ہلکِس لیبلس پیٚٹھ کٲلۍ لائن۔ وٚزٕج لائن مَہ تھٲوِو: واریاہ سکینر چھِ وٚزٕج گاش ورتاوان تہٕ تِم ہیٚکن نہٕ یِمہٕ وُچھِتھ۔
  • لائنن ہِنٛدِس دۄشوَنۍ طرفن ترٲوِو خٲلی سفید جاے؛ ٹول چھُ کینٛہہ مارجن تھاوان۔
  • لیبل مَہ کٔرِو بارکوڈٕچ ضرورتہٕ کھوتہٕ تنگ۔ زیٖٹھِس Code 128 کوڈس گژھن کھُلۍ لیبل؛ سکین نہٕ گژھن تیٚلہِ کٔرِو کوڈ لۄکٹۍ۔
  • تھرمل لیبل چھِ گرمی تہٕ تاپس منٛز پھِکۍ گژھان۔ رؠتھن تام تھاونہٕ وٲلِس سامانس خٲطرٕ ہیٚیِو بہتر لیبل یا تھٲوِو تاپہٕ دوٗر۔
