பார்கோடு › பார்கோடு லேபிள் பிரிண்ட்

ஷீட்டுடன் ஒத்துப்போகும் பார்கோடு லேபிள் பிரிண்ட் செய்வது எப்படி

படிப்படியான பிரிண்டிங், முக்கியமான பிரிண்டர் செட்டிங்ஸ், ஷீட்டை வீணாக்கும் முன் சோதனை, முதல் முறையிலேயே ஸ்கேன் ஆகும் பார்கோடுகள்.

படிப்படியாக

  1. ஐட்டங்களை டிக் செய்யுங்கள், தேவையானால் விலையை மாற்றுங்கள், ஒவ்வொன்றுக்கும் எத்தனை லேபிள் வேண்டும் என்று டைப் செய்யுங்கள். அல்லது உங்கள் ஐட்டங்களில் இல்லாத கோடுக்கு கையால் லேபிள் அழுத்துங்கள்.
  2. ஷீட் அல்லது லேபிள் ரோல், பார்கோடு வகை, என்ன காட்ட வேண்டும் என்பதைத் தேர்ந்தெடுங்கள்: ஐட்டம் பெயர், பார்கோடுக்குக் கீழே கோடு, MRP அல்லது விலை மட்டும், உங்கள் பிசினஸ் பெயர்.
  3. பாதி பயன்படுத்திய ஷீட்டில் லேபிள் எண் முதல் தொடங்கு-வில் முதல் காலி லேபிளை எழுதுங்கள்; எண்ணிக்கை முதல் வரிசையில் இடமிருந்து வலம், பிறகு அடுத்த வரிசையில் செல்லும்.
  4. பிரிவியூ பார்த்து பிரிண்ட் அழுத்துங்கள். A4 ஷீட்டுக்கு PDF பகிர் மூலம் PDF செய்து பின்னர் பிரிண்ட் செய்யலாம்.

முக்கியமான பிரிண்டர் செட்டிங்ஸ்

  • Scale 100% / உண்மை அளவு. "Fit to page" எல்லாவற்றையும் சுருக்கிவிடும், லேபிள்கள் ஷீட்டுடன் ஒத்துப்போகாது.
  • Margins: none (அல்லது minimum), headers மற்றும் footers ஆஃப், அப்போதுதான் பிரவுசர் லேபிள்களில் தேதி, முகவரி அச்சிடாது.
  • ஷீட்டுக்கு பேப்பர் அளவு A4, லேபிள் பிரிண்டருக்கு சரியாக அதே லேபிள் அளவு.
  • லேசர் பிரிண்டர்: லேசருக்காக செய்த ஷீட்களையே வாங்குங்கள்; இங்க்ஜெட் ஷீட்கள் சுருளலாம் அல்லது மை பரவலாம்.

ஷீட்டை வீணாக்கும் முன் சோதியுங்கள்

முதல் பக்கத்தை சாதா பேப்பரில் பிரிண்ட் செய்து, லேபிள் ஷீட்டுடன் சேர்த்து வெளிச்சத்துக்கு முன் பிடியுங்கள்; ஒவ்வொரு பார்கோடும் லேபிளுக்குள் இருக்கிறதா என்று பாருங்கள். எல்லாம் ஒரே பக்கம் நகர்ந்திருந்தால் என் சொந்த அளவு-வில் மேல் அல்லது இடது மார்ஜினை மாற்றுங்கள். பக்கம் முழுவதும் போகப் போக நகர்வு அதிகரித்தால், லேபிள் அகலம் அல்லது இடைவெளி கொஞ்சம் தவறு.

பார்கோடுகள் நன்றாக ஸ்கேன் ஆக

  • வெள்ளை அல்லது வெளிர் லேபிளில் கருப்புக் கோடுகள். சிவப்புக் கோடுகள் வேண்டாம்: பல ஸ்கேனர்கள் சிவப்பு ஒளி பயன்படுத்துவதால் அவற்றைப் பார்க்க முடியாது.
  • கோடுகளின் இரு பக்கமும் காலி வெள்ளை இடம் விடுங்கள்; டூல் சிறிய மார்ஜின் வைக்கும்.
  • பார்கோடுக்குத் தேவையானதை விடக் குறுகிய லேபிள் வேண்டாம். நீண்ட Code 128 கோடுகளுக்கு அகலமான லேபிள் வேண்டும்; ஸ்கேன் ஆகவில்லை என்றால் கோடுகளைச் சுருக்குங்கள்.
  • தெர்மல் லேபிள்கள் வெப்பத்திலும் வெயிலிலும் மங்கும். மாதக்கணக்கில் வைக்கும் பொருட்களுக்கு நல்ல லேபிள் பயன்படுத்துங்கள் அல்லது வெயில் படாமல் வையுங்கள்.
